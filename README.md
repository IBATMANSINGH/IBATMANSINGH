### 💡 My Approach to AI-Assisted Development

Every project listed here was built using a "prompt-first" philosophy. I don't just write code; I architect systems by directing an LLM.

*   **My Process:** Ideation -> Prompt Prototyping -> AI Code Generation -> Debugging & Integration.
*   **My Strength:** Translating a complex goal into a series of clear, effective prompts and then refining the AI's output into a finished product.
